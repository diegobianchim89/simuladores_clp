# Simuladores CLP S7-300

Simulações em HTML para o curso de CLP Siemens STEP 7 (CPU 312C).

- `index.html`: página inicial com a lista de simulações
- `aula02/partida-reversao.html`: partida direta com reversão (slides 23-24)

Para acrescentar uma simulação: crie a pasta da aula, coloque o arquivo .html
e adicione um cartão em `index.html`.
